# Analytics Alert Playbook (Phase 3)

Use this playbook after generating analytics alerts report.

## Alert Categories and Actions

### 古典用神 vs 現代喜用神混淆

- Check lesson 9 wording around 月令、本氣、天透地藏、成格、破格.
- Add one corrective explanation item if the same concept appears repeatedly in alerts.
- Prioritize clarifying differences between classical 用神 and modern 喜用神 terminology.

### 十神名稱會但結構誤讀

- Review lesson 5 prompts that use names without requiring process reasoning.
- Add or rebalance items requiring sequence: relation -> polarity -> structure -> interaction.
- Ensure explanations mention 旺衰、透根、組合, not only names.

### 弱題（低正確率）

- Review distractor quality and ambiguity.
- Check if prompt wording is too compressed for current lesson level.
- Rewrite explanations first, then adjust options if needed.

### 過度曝光題

- Check session selection policy and question pool size for that lesson.
- Add new items to reduce repetition.
- Keep the topic but vary prompt style and context.

## Weekly Routine

- Generate alerts report.
- Prioritize by confusion categories before generic weak-question items.
- Patch lesson copy and banks.
- Re-sync runtime DB.
- Regenerate report and compare category counts.
