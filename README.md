# 輕鬆學八字 (BaZi Learning Game)

輕鬆學八字是一個互動式學習遊戲，幫助你用循序漸進的方式理解八字核心概念。

## 立即開始

遊玩網址：
https://bazi-game-theta.vercel.app/

## 這個遊戲可以做什麼

- 跟著學習路徑從第0課一路到進階內容
- 透過小測驗和總測驗加深記憶
- 查看學習進度、答題表現和連勝紀錄
- 解鎖徽章，讓學習更有成就感

## 遊玩建議

- 先從「第0課：四柱與日主入門」開始
- 每次完成一課後，做一次快速測驗
- 看不懂時先用提示，再重做一次加深印象
- 每天玩一點，比一次塞很多內容更容易記住

## 適合誰

- 完全新手：想從零開始認識八字
- 進修者：想用題目練習觀念判斷
- 教學者：想用互動方式帶學習者入門

## 內容方向

課程涵蓋：

- 四柱與日主
- 五行、天干、地支
- 十神與藏干
- 三合六合、刑沖破害
- 格局取用與實踐應用

## 小提醒

這是一款學習工具，重點是幫你建立分析思路與觀念連結。建議搭配持續練習，效果會更好。
